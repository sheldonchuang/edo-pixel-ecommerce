# 《熱血時代劇》江戶一番街 (FC 1991 復刻電商版)

> 忠實復刻 1991 年 7 月 26 日任天堂紅白機（FC）經典名作**《ダウンタウンスペシャル くにおくんの時代劇だよ全員集合！》（熱血時代劇）**之美術風格、戰鬥招式與 2.5D 江戶街景遊戲化電商原型。

---

## 🎮 經典出招奧義與操作手冊

- **移動與走位**：`W` `A` `S` `D` 或 方向鍵（2.5D 深度舞台，可前後上下跑位避開敵人）
- **跳躍**：`空白鍵 (Space)`（空中可施展飛踢）
- **熱血拳擊**：`J` 鍵（連續出拳、重擊）
- **迴旋飛踢**：`K` 鍵（強力擊退敵人）
- **時代劇必殺奧義【馬赫拳】**：`L` 鍵（高速連續殘像拳，方波急速四連擊！）
- **拾取 / 丟擲武器 / 調查**：`E` 鍵
  - 走近地上掉落的 **【木刀】** 按 `E` 裝備，大幅提升攻擊力與攻擊距離！
  - 裝備武器時再次按 `E` 可將武器擲向敵人！
  - 走近掉落的 **【文錢】** 按 `E` 或踩過可拾起獲得資金！
  - 走近町屋店鋪門口按 `E` 即可進店交談購物。
- **手機/觸控支援**：自動呈現十字鍵、J/K/L/E 虛擬按鍵。

## 🎨 1991 FC 熱血時代劇復刻特色

1. **2.5D 舞台 + 2D 點陣精靈（Billboard Sprites）**：
   - 遠景：駿河灣夕照晚霞、富士山（含視差滾動 Parallax）。
   - 中景：江戶町屋、黑瓦斜頂、千本格子窗、藍/赤暖簾、赤提燈動態點光源。
   - 前景人物與物件：**主角國政（くにまさ）、敵人浪人、木刀、寬永通寶方孔文錢、可打破木箱全數採用 2D 像素點陣 Sprite 繪製**！
2. **打擊感與數值**：
   - 命中敵人即時產生像素硬直、飄浮打擊傷害數字（Damage Float）與擊退擊飛效果。
   - 敵人 HP 歸零後爆炸散落並噴出實體方孔文錢！
3. **純程式 8-Bit Web Audio 合成器**：
   - 無需外載任何 mp3，內建合成 FC 音源晶片方波/三角波/鋸齒波。
   - 內建經典熱血時代劇江戶小調（都節音階）背景音樂（可自由開關 BGM）。
4. **真實電商與 RPG 食補整合**：
   - 在越後屋購買「極上越光米」或「炭烤煎餅」，可直接在遊戲內**回滿體力 HP**！
   - 支援破箱尋得之折價券（`EDO88`）套用 88 折優惠與購物袋下單交割。
